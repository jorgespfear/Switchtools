# Switch Tools
Tres homebrews (NRO) que se compilan solos con GitHub Actions:
- SwitchStorageAnalyzer: analiza el espacio de la microSD
- SwitchSpeedTest: ping, descarga y subida
- SDBenchmark: velocidad de lectura/escritura de la microSD
Descarga el artefacto `SwitchTools-nro` en la pestana Actions y copia los .nro a `sd:/switch/`.
